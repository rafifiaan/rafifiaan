## 🚀 About Me

I'm an IT Automation Test Engineer who enjoys building automation that makes testing faster, more reliable, and easier to maintain.

My main stack includes Java, Selenium WebDriver, Appium, REST Assured, and Postman. My software engineering background gives me a deeper understanding of backend systems, helping me design more reliable and maintainable test automation.

Currently expanding my expertise toward Software Development Engineer in Test (SDET) while exploring AI, LLMs, and intelligent automation.
